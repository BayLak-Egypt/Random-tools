
## Libraries Required

This project requires the following Python library:

```bash
pip install requests
```

> Note: Other libraries like `sys`, `os`, `json`, `threading`, `datetime`, and `concurrent.futures` are included in standard Python, no need to install separately.

---

## How to Use

1. **Watch Links**

To watch or view links, run:

```bash
python3 readtopic.py
```

2. **Download All**

To download everything, run:

```bash
python3 main.py
```

---

## Notes

* Make sure you have Python 3 installed.
* Ensure `requests` library is installed before running the scripts.
