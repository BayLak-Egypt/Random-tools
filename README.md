## 🌀 What's inside?
This repository is a mix of everything useful. No specific niche—just scripts that make life easier.

* 🛠️ **Automation:** Scripts to handle repetitive tasks.
* 🐍 **Python Scripts:** Various utilities from web scrapers to data tools.
* 📂 **File Managers:** Bulk renaming, compression, and cleanup.
* 🌐 **Networking:** Quick tools for IP info, speed tests, and pings.
* 🧪 **Experimental:** New ideas and coding playground.
