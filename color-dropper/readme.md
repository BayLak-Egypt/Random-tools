# Color Dropper - v1.0
![Screenshot](https://github.com/BayLak-ONE/Random-tools/blob/main/color-dropper/Screenshot%20from%202025-12-21%2022-33-23.png)
A professional, high-precision color extraction tool designed for designers and developers. Extract HEX and RGB codes from any image or GIF with ease.

## 🚀 Features
- **Smart Zoom:** Use the mouse wheel to zoom in up to 1000% for pixel-perfect accuracy.
- **Precision View:** A dedicated magnifying glass window showing the exact pixel under your cursor.
- **Edge Panning:** Move the image just by hovering near the edges (Game-style navigation).
- **Pro Dragging:** Hold **Right-Click** to drag and move the image freely.
- **GIF Support:** Works with standard images (JPG, PNG, BMP) and animated GIFs.
- **Quick Copy:** One-click buttons to copy HEX or RGB values to your clipboard.
- **Modern UI:** Sleek dark-themed interface.
